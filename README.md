# Multi-Restaurant-Food-Ordering-Delivery-Dispatch-System
Hệ thống đặt món và điều phối giao hàng cho nhiều nhà hàng

## Phần M2 của Hưng

Mã nguồn, hướng dẫn chạy và kết quả audit nằm trong [M2/README.md](M2/README.md). Gói dùng Node.js 24 + Express, dữ liệu giả trong RAM; không chứa phần database M3.

Đây là nhánh bàn giao công việc M2. Bản tích hợp chạy MySQL của nhóm nằm trên nhánh main.
